# 파일뚝딱

파일을 서버에 업로드하지 않고 브라우저에서 처리하는 한국형 이미지·PDF 도구 MVP입니다.

## 포함된 도구

- 이미지 용량 줄이기: JPG, PNG, WEBP 품질·크기·형식 설정
- HEIC → JPG: 아이폰 사진 변환 및 화질 설정
- 사진 → PDF: 최대 30장, 순서·A4·여백 설정

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 빌드 결과 확인은 `npm run preview`를 사용합니다.

## 개인정보 보호

파일 변환은 모두 사용자의 브라우저 메모리 안에서 실행됩니다. 선택한 파일을 외부 서버로 전송하거나 보관하지 않습니다.
