# HWP/HWPX 호환 PDF 정책

## 제품 계약

파일정비소는 HWP/HWPX를 원본과 동일하게 변환한다고 보장하지 않습니다. 현재 기능의 정확한 이름은 **호환 PDF**이며, 텍스트 검색이 제한되는 이미지형 결과입니다.

| 입력 | 처리 방식 | 보장 범위 |
| --- | --- | --- |
| HWP 5.0 | `@rhwp/core` WASM 페이지 렌더링 | 렌더러가 지원하는 페이지의 화면 이미지 |
| HWPX | XML 구조 검사 후 호환 레이아웃 생성 | 일반 본문, 단순 표의 행·열·테두리 |

원본과 동일한 PDF가 필요하면 한컴오피스의 `파일 → PDF로 저장하기`를 사용해야 합니다.

## 변환 전에 거부하는 입력

- 파일 확장자와 실제 OLE/ZIP 서명이 일치하지 않는 파일
- HWPX 본문 XML이 없거나 손상된 일반 ZIP 파일
- 비어 있거나 20MB를 초과하는 파일
- 내부 항목 또는 XML 크기가 안전 제한을 초과하는 HWPX
- 암호, DRM, 배포용 보호가 적용된 문서
- 페이지 수가 50페이지를 초과하는 HWP 5.0 문서

## HWPX 사전 점검

변환 전에 본문, 표, 구역 수를 표시합니다. 이미지, 도형, 수식, 차트, 병합 셀, 중첩 표, 머리글·바닥글·각주가 감지되면 유지되지 않는 요소로 명시합니다. 사용자가 한계를 확인하는 체크박스를 선택해야 변환 버튼이 활성화됩니다.

긴 문단과 한 페이지보다 높은 표 행은 페이지 단위로 나누며, 각 페이지 사이에 브라우저 이벤트 루프를 양보합니다. 사용자는 페이지 사이에서 변환을 취소할 수 있습니다.

## 보안 경계

- 원본과 결과는 애플리케이션 서버로 전송하지 않습니다.
- HWPX ZIP은 CRC, 내부 항목 수, 본문 XML 존재 여부와 누적 XML 크기를 확인합니다.
- 출력 파일명에서 제어 문자와 운영체제 금지 문자를 제거합니다.
- 제3자 광고·분석 스크립트를 추가하면 개인정보처리방침, 동의 방식과 CSP를 먼저 갱신해야 합니다.

## 의도적으로 제공하지 않는 기능

- 원본과 동일하다고 주장하는 브라우저 HWP/HWPX → PDF
- PDF → HWP/HWPX
- 암호·DRM·배포용 보호 해제

정밀 변환을 추가하려면 한컴 공식 엔진의 상업적 서버 라이선스, 격리된 작업 실행 환경, 악성 파일 검사, 암호화된 임시 저장소, 자동 삭제와 감사 가능한 보존 정책이 모두 필요합니다.
